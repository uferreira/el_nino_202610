About the model

The potential V(X) = −K1·X²/2 − K3·X⁴/4 has two wells when K1 > 0 and K3 < 0, read as the warm (El Niño) and cool (La Niña) states. The periodic forcing, read as the annual trade-wind cycle, pushes the state between the wells; damping (B < 0) removes energy.

The El Niño fit uses the coefficients of the original Java applet. They were not re-estimated from the records on this site, so it is a hypothesis to compare with the observations (see the Compare page), not a validated fit.

Play draws the trajectory through time: a dot moves along it, the last forcing cycle trails behind it in red, and the path builds up behind; the time series marks the same moment. The Poincaré section has its own play button, which steps the phase of the forcing.

Each run integrates one trajectory with scipy's RK45 (relative tolerance 1e-6), discards the first forcing cycles as transient, and keeps the rest. The section shows that same trajectory once per forcing cycle; it is not a cloud of different starting points. Runs are cached in the repository, so the pages always show the same trajectory.

Data: NOAA CPC SST indices (monthly, and weekly for NINO1+2), UHSLC tide gauges (hourly, averaged to months). Data last changed 4 Nov 2026; last checked for new data: Sea surface temperature 6 Nov 2026, sea level 4 Nov 2026.
