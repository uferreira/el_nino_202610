How the records are scaled

Each record is put on the same dimensionless plane: xn = (x − mean) / σx and yn = (dx/dt) / σx, with the mean and standard deviation σx of that record's filtered values over its analysis window. Both axes use the same σx, so each loop keeps its shape: a taller loop is a record that moves faster relative to its own typical swing.

The time strip shows each record's filtered anomaly (seasonal cycle removed) divided by that anomaly's own standard deviation, so El Niño events line up across records whatever their units or seasonal swing. The model has no real calendar, so it is on the loops and the section but not on the time strip.

Play runs every chosen record on the same calendar: one dot per record, each at the same month, with its last 12 months trailing behind and its path building up; the time strip marks that month on each record. A highlighted El Niño or dragged period plays alone. The model has no calendar, so it stays drawn whole and does not move.

The annual section keeps one point per year, in the chosen calendar month. Records that share a seasonal rhythm cluster in the same part of the plane for the same month.

Data: NOAA CPC SST indices (monthly, and weekly for NINO1+2), UHSLC tide gauges (hourly, averaged to months). Data last changed 13 Nov 2026; last checked for new data: Sea surface temperature 12 Nov 2026, sea level 13 Nov 2026.
